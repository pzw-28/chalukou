# 变更 001：国考三态筛选、逐行溯源与地点差分

- 日期：2026-10-30（America/New_York）
- 状态：GPT 复审阻断项已修订，按用户“全力做完”指示进入执行
- 作者：Kimi Code
- 独立审查：GPT；先提出 5 项风险，复审再提出 4 个阻断项，本版逐项处置
- 核心原则：数字由程序从官方职位表计算，AI 只讲解。

## 1. 真实问题与目标

大三学生面对近万条国考职位，难以回答“以我的条件究竟能报哪些岗位，改一个地点会增加哪些岗位”。本变更交付一个可双击打开的 `index.html`，让用户导入官方 Excel 后完成画像输入、三态筛选、职位原表核验和地点差分。

## 2. 已核验的数据事实

- 来源：国家公务员局 2027 年度考录专题“相关下载”页面，http://bm.scs.gov.cn/pp/gkweb/core/web/ui/business/download/gkdownloads.html
- 文件：`中央机关及其直属机构2027年度考试录用公务员招考简章.xls`
- 当前保留文件 SHA256：`6b3da70baabe31a4a202c6b1179040db7003a956bc85c79cd35e3fb739d9520a`
- 用户另行上传的 `.xls` 二进制 SHA256 不同，但 SheetJS 逐单元格内容哈希相同；不得混称二进制版本相同。
- 四个数据 sheet 均为第 1 行说明、第 2 行 27 列表头、第 3 行起职位，共 19,426 条；空白 `Sheet1` 跳过。
- 首条职位必须从 Excel 第 3 行开始，物理行号在排序和筛选后仍保持不变。
- 原表没有独立“是否应届”列，部分届别、身份和其他硬门槛写在备注中。

## 3. 本次做什么

1. 单文件页面通过 CDN 加载 SheetJS，直接读取用户选择的原始 `.xls`，不转换、不修改原文件。
2. 校验真实 sheet 和第 2 行表头；缺列或结构不符时停止筛选并显示错误，不猜字段。
3. 每条职位保留全部原始字段、来源文件名、sheet、真实 Excel 行号和稳定 ID（数据版本＋sheet＋行号）。职位代码只作普通字段，不单独用于去重。
4. 画像输入：专业、学历、学位、政治面貌、应届情况、基层工作年限、可接受工作地点（多选）。应届情况区分“2027 届／非 2027 届／不确定”，不用简单布尔值冒充届别。
5. 纯程序逐条件判定符合、不符、待确认：
   - 专业“不限／专业不限”可符合；其余按对应学历阶段匹配完整专业项，跨学历阶段不得放行；大类、方向、排除语义或无法可靠解释时待确认。涉及其他学历阶段而资料不足时同样待确认。
   - 学历按“仅限／或／及以上”分别处理；学位独立校验；不得把“仅限硕士”解释为博士也符合。
   - 政治面貌按原表集合判断；基层年限按用户实际年限与要求比较，用户不确定时待确认。
   - 服务基层项目身份今晚不采集；原表要求非“无限制”且身份未核实时待确认。
   - 原文明确限定“2027届”时才比较届别；一般“限应届高校毕业生”等身份要求，现有输入不足以证明时待确认，不把“非2027届”等同于“非应届”。
   - 未解释或未核实的备注内容不能默认通过；只有空备注或已确认属于纯说明的内容才可不计为待确认。涉及亲属回避、多个学历阶段、证书、经历等未核实限制时保留待确认。
   - 汇总顺序：任一不符则整体不符；否则任一待确认则整体待确认；全部已核实符合才整体符合。
6. 显示三态计数；点击计数展开对应职位列表；点击职位查看 sheet、Excel 行号、原始字段，并标红不符条件、标黄待确认条件。
7. 地点差分基线绑定“当前数据版本＋全部非地点画像”。只改变工作地点时立即重算，显示相对上一地点的符合职位变化量和新增符合职位；改变其他画像字段或重新导入数据时清空旧差分并建立新基线，不把版本或画像变化错误归因于地点。
8. 页面顶部固定显示：“所有数字由程序从官方职位表算出，可点开查看原表行号”。界面简洁、适合 1080p 录屏。

## 4. 明确不做什么

- 不做 AI 讲解员、DeepSeek 调用、数字合同或回放。
- 不做考研、就业、成功率、上岸概率、进面线预测、学院端、账号或数据库。
- 不建立完整专业目录，不用 AI 决定资格，不声称已解释所有备注。
- 不迁移 Next.js；预指导版技术例外与正式版迁移计划写入项目说明。
- 不使用合成数据，不复制参考项目代码，不伪造测试或 Prompt 链。

## 5. 验收标准

1. 双击 `index.html` 后能选择官方 `.xls`；程序识别四个数据 sheet、19,426 条职位，空白 sheet 不参与计数。
2. 每表首条职位显示 Excel 第 3 行；中央党群机关第 92 行备注完整包含“专业能力测试成绩占综合成绩15％”。
3. 省级以下直属机构第 3、4 行职位代码相同，但两条均保留且分别打开北京市通信管理局、内蒙古自治区通信管理局。
4. 本科计算机画像不能把中央党群机关第 67 行仅在研究生段开设计算机的职位判为专业符合。
5. 对中央党群机关第 76 行，博士不能被“仅限硕士研究生”放行。
6. 参公事业单位第 128 行在毕业届别未知时不得判符合；省级以下直属机构第 16993 行的一般“限应届高校毕业生”不得被“非2027届”直接判不符或符合；第 421 行在退役身份未知时不得判符合。
7. 固定真实正例：中央党群机关第 58 行，画像为法学、本科、学士、政治面貌不限、基层二年、地点北京市东城区；备注为空且其余原表条件匹配时，逐项结果与整体结果均为符合。另以第 67 行覆盖专业待确认、第 76 行博士画像覆盖整体不符，防止实现恒为待确认或恒为零。
8. 三态计数之和等于参与计算的职位总数；每个计数展开的职位数与计数一致，详情中的 sheet、Excel 行号和原始字段可回查。
9. 固定地点差分：使用第 58 行正例画像，从仅选“北京市西城区”变为增加“北京市东城区”，变化量必须非零且新增稳定 ID 必须包含中央党群机关第 58 行。再执行“导入→地点变化→重新导入→再次改变地点”，确认重新导入后旧差分已清空且版本变化不计入新增。
10. 页面无虚构数字、无 API Key、无未标明的演示数据；在 Windows 浏览器实际完成一次“导入→画像→三态→溯源→改地点”操作并记录结果。
11. README 能让新用户在 10 分钟内取得官方数据并打开页面，写明数据年份、预指导范围和后续 Next.js 迁移计划。

## 6. 主要风险与边界

- 保守三态会产生较多待确认，这是有意避免假符合，不为演示效果降低门槛。
- SheetJS 使用 CDN，首次打开需要网络；官方 Excel 由用户本地选择，不上传到服务器。
- 预指导版只证明本提案列出的规则与真实样例，不宣称覆盖所有报考资格；最终结果以招录机关审核为准。
