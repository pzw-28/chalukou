# P-003 官方 Excel 导入与空白 sheet 排错

- 日期：2026-10-30（America/New_York）
- 对应提交：`feat: 读取官方职位表并保留原表行号 [P-003]`
- 用的 AI：Kimi Code

## 我的提问

按 001 的 T02 实现单文件 Excel 导入，必须保留真实 sheet、27 列原文字段、物理行号和稳定 ID；空白 sheet 不参与计算。

## AI 的方案 / 修改建议

使用 SheetJS 在浏览器本地解析 `.xls`，先计算 SHA256，再校验第 2 行表头。每条职位使用“文件哈希＋sheet＋Excel 行号”作为稳定 ID，不使用职位代码去重。

## 我怎么引导（含排错过程）

- 复现：首次导入自检在空白 `Sheet1` 报“缺少第 2 行表头”。
- 根因：空表判断只检查 `rows.length`，但该 sheet 实际返回 `[['']]`，长度为一而没有实际内容。
- 证据：最小探测输出 `length 1 rows [[""]] hasContent false`。
- 修改：改为检查所有行是否含任何非空单元格，真正空白才跳过。
- 后续测试又出现只读 `Sheet1`：这是 Node 与 VM 沙盒的 ArrayBuffer 跨 realm 问题，不是产品逻辑；改用沙盒内创建的 ArrayBuffer 后重跑，没有为测试环境修改浏览器实现。

## 结果与验证

对实际 `index.html` 中的 `parseWorkbook` 运行真实官方文件，断言全部通过：

- 19,426 条职位，4 个数据 sheet；首条 Excel 行号为 3。
- 中央党群机关第 92 行备注包含完整“专业能力测试成绩占综合成绩15％”。
- 省级以下直属机构第 3、4 行重复职位代码均保留，部门不串。
- 19,426 个稳定 ID 全部唯一。

这是一轮真实的“复现→根因→证据→修改→验证”排错记录。
