# 岔路口

可核验的考研、就业、考公选择沙盘。预指导版先聚焦国考：**数字由程序从官方职位表计算，AI 不参与资格判定。**

公开仓库：https://github.com/pzw-28/chalukou

## 预指导版能做什么

- 在浏览器本地读取官方 2027 国考招考简章 `.xls`，不上传文件。
- 输入专业、学历、学位、政治面貌、毕业届别、基层年限和可接受地点。
- 逐职位输出“符合 / 不符 / 待确认”，不确定条件绝不擅自放行。
- 点击计数查看对应职位；点击职位查看真实 sheet、Excel 行号、27 列原始字段和未满足条件。
- 只改地点时显示符合数变化量和新增职位；重新导入或改其他画像会清空旧差分。

## 10 分钟复现路径

不需要 Node、npm、Python、数据库或 API Key。首次打开需要联网加载 SheetJS CDN。

1. 克隆仓库：

   ```bash
   git clone https://github.com/pzw-28/chalukou.git
   ```

2. 仓库已保留官方文件：`data/raw/中央机关及其直属机构2027年度考试录用公务员招考简章.xls`。如需重新下载，只使用国家公务员局 [2027 考录专题相关下载](http://bm.scs.gov.cn/pp/gkweb/core/web/ui/business/download/gkdownloads.html)，不要用培训机构职位库。
3. 用新版 Edge 或 Chrome 双击打开根目录 `index.html`。
4. 点击“选择官方 .xls 文件”，选中上述 Excel，等待原表结构核验完成。
5. 可使用默认画像体验：法学、本科、学士、群众、基层二年、北京市东城区。然后点计数、点职位、修改地点查看差分。

如果浏览器提示 SheetJS 未加载，请检查网络后刷新；本版不伪造离线数据结果。

## 数据与口径

- 数据年份：2027 年度国考。
- 来源：国家公务员局 2027 年度考录专题。
- 四个数据 sheet 均为第 2 行表头、第 3 行首条职位，共 19,426 条；空白 `Sheet1` 不参与计算。
- 当前保留文件 SHA256：`6b3da70baabe31a4a202c6b1179040db7003a956bc85c79cd35e3fb739d9520a`。
- 完整数据档案见 `data/manifest.json`。用户另一份同内容 XLS 的二进制哈希不同，已逐单元格确认内容一致，未混称二进制版本相同。

默认画像的实际程序结果：符合 1、待确认 12、不符 19,413。地点变化会改变这些数字，页面不硬编码结果。

## 边界

- 专业按学历阶段和完整专业项匹配；大类、方向、跨阶段或其他歧义进入待确认。
- 一般应届身份、服务基层项目身份、证书、经历、亲属回避及未解释备注不会被擅自判为满足。
- 待确认较多是保守设计，不是把不符强行隐藏。最终报考资格以招录机关审核为准。
- 预指导版不做 AI 讲解员、数字合同、回放、考研就业、成功率预测、账号或数据库。
